================================================================================

Implemented core scope:
  - API prediction count, error count, and latency histogram;
  - Prometheus-format /metrics endpoint;
  - data-quality reports and warnings;
  - PSI and KS tests for continuous features;
  - chi-squared tests for categorical features;
  - retraining signals for new labels, AUC drop, drift, and model age;
  - JSON drift and retraining-decision logs.

Automation boundary:
  RetrainingTrigger decides eligibility and logs why. It does not automatically
  start training. The configured weekly cron is a proposed policy; no scheduler
  is installed. Actual retraining remains a human- or CI-triggered train/evaluate
  workflow.

11. TROUBLESHOOTING
================================================================================

Problem: ModuleNotFoundError
Action:  Confirm the current directory is the project root and activate venv.

Problem: TensorFlow import or wheel failure
Action:  Use Python 3.9 and the existing verified venv where available. Do not
         replace the TensorFlow candidate with sklearn MLPClassifier.

Problem: FileNotFoundError for model/preprocessor/threshold
Action:  Confirm the saved artifacts listed in Section 4 exist. If they were
         intentionally removed, run both training commands followed by evaluation.

Problem: Evaluation command returns status 1
Action:  Read artifacts/eval/model_comparison.json. Status 1 is expected when the
         candidate fails promotion and the baseline is safely retained.

Problem: API connection refused
Action:  Start Uvicorn first and use host 127.0.0.1, port 8000.

Problem: /health says model_loaded=false or startup fails
Action:  Validate models/current_best.json and every referenced artifact path.

Problem: Prometheus/Grafana URL does not respond
Action:  Run docker compose -f docker/docker-compose.yml up -d api prometheus grafana
         and then python scripts/verify_monitoring_stack.py. Inspect container
         health and logs if the retained verification checks do not pass.
